# 🚗 Calculadora de trajectes

Vols calcular quant et costarà fer un trajecte en cotxe? ací tens tota una GUIA COMPLETA per a que t'indique el preu del viatge!

### 📍 Planifica el teu viatge, calcula els costos i optimitza els teus desplaçaments.

Una ferramenta interactiva per a **calcular, comparar i planificar trajectes per carretera** de manera senzilla i intuïtiva. Consulta les estimacions, analitza les despeses i pren decisions més informades abans de posar-te en marxa.

---

## ✨ Característiques

- 🛣️ **Planificació de trajectes:** facilita l'anàlisi dels teus desplaçaments.
- 💰 **Càlcul de costos:** estima les despeses associades (preu combustible, desgast, peatges, etc.) al trajecte segons les dades introduïdes.
- ⚡ **Ràpida i intuïtiva:** una interfície senzilla per a fer càlculs sense complicacions.
- 📱 **Adaptada a diferents casuístiques:** configura-la per a diferents tipus de vehicles, consums, característiques.
- 🌐 **Accés en línia:** no cal instal·lar cap programa; només necessites un navegador i connexió a Internet.

## 🚀 Com funciona?

1. Accedeix a la calculadora.
2. Introdueix les dades necessàries per al trajecte: Origen-Destinació, kilòmetres(els calcula automàticament o manualment), tipus de vehicle, preu del combustible, peatges, només anada o anada+tornada, nombre de passatgers, etc.  
3. Consulta els resultats obtinguts.
4. Utilitza la informació per a planificar i optimitzar el teu desplaçament.

## 🎯 Objectiu

Facilitar la planificació dels desplaçaments mitjançant una ferramenta pràctica, accessible i fàcil d'utilitzar, que permeta calcular costos i valorar diferents opcions de viatge.
